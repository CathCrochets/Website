# Cath Crochets storefront

A responsive, static storefront concept for **Cath Crochets**, handmade in Newcastle upon Tyne.

## Local preview

Open `index.html` directly, or serve this directory with any static file server.

## GitHub Pages

The deployable site is at the repository root. In GitHub, choose **Settings → Pages → Deploy from a branch**, then select the main branch and `/ (root)`. The included `CNAME` file is set to `cathcrochets.co.uk`.

## Before taking live orders

- Connect checkout to Stripe, Shopify, Snipcart, or another payment/order provider.
- Connect the newsletter form to an email platform.
- Confirm that `hello@cathcrochets.co.uk` exists, or replace it throughout `index.html` and `app.js`.
- Replace the placeholder Instagram link in `index.html` with Cath's real profile.
- Confirm postage prices, dispatch times, business identity, returns address, and policy wording.
- Add real analytics only after wiring it into the consent choice.
- Compress or replace screenshot-derived product images with Cath's original listing photography when available.

## Current front-end features

- Responsive product catalogue, categories, search, and sorting
- Product quick-view dialogs
- Persistent local basket with quantity controls and free-delivery threshold
- Clearly labelled checkout preview (no payment is taken)
- Custom-order enquiry via a pre-filled email
- Newsletter concept state
- Privacy, cookie, delivery, returns, and terms content
- Cookie preference control and local-storage disclosure
- SEO metadata, structured data, sitemap, robots file, and custom-domain file

All prices and shop facts were transcribed from the supplied CathCrochetsUK Etsy screenshots in August 2026.
